# Fundamentos de Desarrollo Web — código del curso

Curso en video de **HTML y CSS** para estudiantes de secundaria (12 a 17 años) que nunca han programado. Dura aproximadamente 1 hora y está dividido en lecciones cortas en YouTube.

**No hay que instalar nada.** Todo se practica en el navegador, con editores en línea gratuitos (CodePen y JSFiddle).

> 📺 Las lecciones y los enlaces a cada práctica están en [curso-plan.md](curso-plan.md).

## Cómo usar este repositorio

1. Mira la lección en YouTube.
2. Abre el enlace del editor en línea de esa lección y practica ahí mismo.
3. Si quieres comparar tu trabajo, usa los archivos de este repositorio:
   - `starter-files`: el punto de partida de cada práctica.
   - `completed-examples`: el resultado final de cada práctica.

## Configuración

No necesitas instalar nada para seguir el curso.

Si quieres ver los archivos en tu computador:

1. Presiona el botón verde **Code** y elige **Download ZIP**.
2. Descomprime la carpeta descargada.
3. Entra a la carpeta de una lección y abre el archivo `index.html` con doble clic. Se abrirá en tu navegador.

Para editar el código, copia el contenido de los archivos `index.html` y `style.css` en el editor en línea de la lección.
