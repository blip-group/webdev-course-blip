# starter-files

Código de **partida** de cada práctica del curso. Cada lección tiene su propia carpeta (`leccion-1`, `leccion-2`, etc.).

Para practicar no necesitas instalar nada: abre el enlace del editor en línea de la lección (están en [curso-plan.md](../curso-plan.md)) y copia aquí el contenido de `index.html` y `style.css` si quieres empezar desde este punto.

| Carpeta | Contenido |
|---|---|
| [`leccion-6/pagina-base`](leccion-6/pagina-base) | La página de perfil «sana» que se usa para mostrar los errores |
| [`leccion-6/reto-encuentra-el-error`](leccion-6/reto-encuentra-el-error) | La página con 3 errores escondidos |
