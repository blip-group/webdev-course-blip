## Escena 2 — El navegador (0:23–1:04)

**En pantalla:** un dibujo de «código → navegador → página».

> Cuando abres Chrome, Edge, Firefox o Safari, estás usando un navegador. Un navegador es un programa que sabe leer código y convertirlo en lo que ves en la pantalla: textos, imágenes, botones y colores.
>
> Detrás de cada página hay un archivo de texto con instrucciones. El navegador las lee de arriba hacia abajo, una por una, y va dibujando la página.
>
> Si cambias las instrucciones, cambia la página. Y eso es justo lo que vas a aprender a escribir en este curso.

## Escena 3 — HTML, CSS y JavaScript (1:04–2:06)

**En pantalla:** tres tarjetas: HTML (el esqueleto), CSS (la apariencia) y JavaScript (los músculos).

> Una página web se construye con tres lenguajes. Para entenderlos, imagínalos como una persona.
>
> El primero es HTML. HTML es un lenguaje de marcado: sirve para marcar qué es cada parte de la página, por ejemplo, esto es un título, esto es un párrafo. Es el esqueleto: la estructura que sostiene todo lo demás.
>
> El segundo es CSS. CSS es la apariencia: el color del cabello, el color de los ojos, la ropa, el estilo.
>
> El tercero es JavaScript. JavaScript son los músculos y las articulaciones: lo que da movimiento y hace que la página sea más funcional.
>
> En este curso vamos a usar solo HTML y CSS. JavaScript lo dejamos para más adelante.

## Escena 4 — Las etiquetas son cajas (2:06–3:29)

**En pantalla:** cajas que se meten una dentro de otra: `html` → `head` y `body` → `h1` y `p`; y el ejemplo «Hola, mundo».

> Veamos cómo se escribe el esqueleto. HTML funciona con etiquetas, y una etiqueta es como una caja con nombre. Se abre con el símbolo menor que, el nombre y el símbolo mayor que. Se cierra igual, pero con una barra antes del nombre. Y entre las dos va el contenido.
>
> La caja más grande se llama `html`, y guarda toda la página. Dentro hay dos cajas. La primera es `head`, que significa cabeza: guarda información que no se ve en la página, como el título que aparece en la pestaña del navegador. La segunda es `body`, que significa cuerpo: aquí va todo lo que sí se ve.
>
> Dentro de `body` vamos a usar dos cajas muy comunes: `h1`, para el título principal, y `p`, para un párrafo.
>
> Por ejemplo: abres la caja `h1`, escribes «Hola, mundo» y cierras la caja. El navegador lo muestra como un título grande. Tu «Hola, mundo» puede decir el saludo que más te guste.
>
> Cuando uses el editor en línea, la estructura ya viene lista: tú solo escribirás lo que va dentro del cuerpo.
